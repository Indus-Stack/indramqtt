`gcp_pubsub_producer` sends each result row to a Google Cloud Pub/Sub topic.

It is the documented name for the `gcp_pubsub` sink. The v5 route maps the name to the `gcp_pubsub` runtime and keeps the name on the stored row. The v1 route refuses the name. The tier of the name is community. The base runtime is enterprise. See the `gcp_pubsub` page for the full settings.
