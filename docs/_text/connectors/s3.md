`s3` writes each result batch to an Amazon S3 or S3-compatible bucket. The v1 route accepts `s3` and `minio`. The v5 route accepts `s3`. The tier is community.

The v1 route reads the full sink settings. The v5 route reads the endpoint, the bucket, the region, the credentials, the key template, and the timeout. It fixes the compression and the batch policy. The `s3` page documents both shapes.
